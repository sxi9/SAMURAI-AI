# SAMURAI — labeled screenshots of every feature

Every image was captured from the real build by `docs/screenshots/shots.js` against the running services (software rendering in a container, so the 3D core is on its low profile; on a real GPU it is sharper and smoother). The numbered badges in each picture match the captions below. The install steps have their own labeled set in [INSTALL.md](INSTALL.md).
